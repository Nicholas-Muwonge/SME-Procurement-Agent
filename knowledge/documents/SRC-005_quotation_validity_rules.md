# Supplier Quotation Validity Rules

## 1. Validity Period
A quotation is considered valid only if the current date is on or before the “Valid Until” date shown on the quotation.

## 2. Expired Quotations
- Expired quotations must not be used for drafting a new purchase requisition.
- The system should clearly mark any expired quotation as “Expired”.
- If all quotations for an item are expired, the system must state that no valid quotations are available.

## 3. Missing Validity Date
If a quotation has no validity date, it should be treated as invalid until clarified by the procurement officer.
