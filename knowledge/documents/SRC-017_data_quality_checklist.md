# Inventory Data Quality Checklist

Before trusting inventory figures, the following checks are recommended:

1. Is the Current Stock value present and numeric?
2. Is the Reorder Point present and numeric?
3. Is the Reorder Quantity present and greater than zero?
4. Was the stock figure updated within a reasonable time period?
5. Are units consistent (bags, pieces, kg)?

If any critical field fails these checks, the item should be flagged as having insufficient data and excluded from automatic recommendations until corrected.
