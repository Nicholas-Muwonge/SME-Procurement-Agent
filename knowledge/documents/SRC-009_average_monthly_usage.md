# Average Monthly Usage Calculation Method

## Simple Method Used by the System
Average Monthly Usage = Total quantity issued over the last 3 months ÷ 3

## Notes
- This figure is used only to support explanations of reorder recommendations.
- It must not automatically override the static Reorder Quantity stored in the inventory record.
- If less than 3 months of data is available, the system should note that the usage figure is based on limited history.
