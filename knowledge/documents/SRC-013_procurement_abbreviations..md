# Common Procurement Abbreviations

| Abbreviation | Meaning                          |
|--------------|----------------------------------|
| PO           | Purchase Order                   |
| PR           | Purchase Requisition             |
| RFQ          | Request for Quotation            |
| MOQ          | Minimum Order Quantity           |
| LT           | Lead Time                        |
| RO           | Reorder                          |
| RP           | Reorder Point                    |
| SOH          | Stock on Hand (Current Stock)    |
| GRN          | Goods Received Note              |
| VAT          | Value Added Tax                  |

Use full terms in formal documents whenever possible.
