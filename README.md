# SME-Procurement-Agent


## Project Overview
Bounded agentic system that helps a Ugandan SME procurement officer prepare purchase requisitions.  
The system detects low stock, recommends reorder quantities, compares supplier quotations, drafts a requisition and routes it for mandatory human approval.
